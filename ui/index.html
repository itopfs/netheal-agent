Welcome to NetHeal Agent

NetHeal Agent is a network simulator that demonstrates an AI agentic loop for self-healing networks. An autonomous LLM acts as an operator: it investigates incidents, selects diagnostic and repair tools, and works toward restoring connectivity — without a fixed, scripted playbook.

  • Seven predefined scenarios — each with a different network fault; the number and sequence of tools vary, with no single predetermined path to success.
  • No topology or root-cause map — the LLM receives only the incident report and a catalog of available tools.
  • Observe → decide → act — each turn it reasons from the latest observations, chooses the next tool and parameters, executes it, and adds the result to its context.
  • Stop when done — the loop continues until the agent verifies a fix or escalates a fault that cannot be repaired remotely.
  • Non-deterministic — the same scenario can produce a different tool order and step count on each run, because selection is driven by model reasoning, not hardcoded rules.

How to begin:

  1. Select a scenario from the left panel.
  2. Click Troubleshoot & Heal to start the agent.
  3. Follow the topology, decisions, and timeline as the observe → decide → act loop unfolds.

In a real network:

The same loop would be driven by live inputs such as service-desk tickets, monitoring alarms, or NOC dashboards instead of predefined scenarios. The agent would call real diagnostic and change APIs (or controlled automation runbooks) on production devices, apply a verified fix or escalate to an engineer when remote repair is not possible, and leave an auditable trail of every decision and action.
